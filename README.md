# PepperwoodLFM
Pepperwood Live Fuel Moisture Project, started Fall 2021

## Claude Code workflow files (git-ignored)

The following files are used for AI-assisted development with Claude Code and are not tracked in version control:

- **`CLAUDE.md`** — Token efficiency rules and workflow conventions (session hygiene, data inspection, output diagnostics)
- **`docs/session-log.md`** — Dated session summaries (goals, decisions, files changed, next steps). Newest entries first.
- **`docs/tasks.md`** — Running task list (In Progress / Up Next / Backlog / Completed). Single source of truth for planned work.
- **`docs/literature-notes.md`** — Brief summaries of papers read from the `literature/` folder, with key points and relevance to this project.
